# Python-Projects

A collection of Python programming projects and exercises spanning data analysis, automation, and problem-solving.

## Overview

This repository brings together Python work done across personal projects and coursework, demonstrating proficiency in core Python as well as data-focused libraries.

## Skills Demonstrated

- **Core Python** — Data types, control flow, functions, OOP, file I/O
- **Data Analysis** — pandas, NumPy for data manipulation and exploration
- **Visualization** — matplotlib, seaborn for charts and plots
- **Automation** — Scripts for repetitive tasks and data processing workflows
- **Problem Solving** — Algorithm and logic exercises

## Tools & Libraries

| Library | Purpose |
|---------|---------|
| pandas | Data frames and analysis |
| NumPy | Numerical computing |
| matplotlib / seaborn | Data visualization |
| scikit-learn | Machine learning |
| os / sys / json | Standard library utilities |

## Structure

Projects and exercises are organized by topic or use case in subdirectories.
